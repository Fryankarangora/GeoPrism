# GeoPrism

GeoPrism is a real-time geospatial data processing engine with automated data integration capabilities.

With GeoPrism, you get a lightweight tool that stays out of your way.

**What you get**

- GeoPrism is a real-time geospatial
- data processing engine with automated
- data integration capabilities

## Key Features

- GeoPrism is a real-time geospatial
- data processing engine with automated
- data integration capabilities

## Technology Stack

- php
- php framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/GeoPrism.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

GeoPrism is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
